# Issue tracker: Linear

Issues and product requirements for this repository live in Linear.

Use the Linear MCP tools for all issue operations.

## Scope

- Workspace: `acolhe`
- Team: `Acolhe`
- Team key: `ACO`
- Project: `API`
- Project ID: `8ffd52fb-2caa-4935-b37b-3d71c8f98efa`
- Project URL: https://linear.app/acolhe/project/api-e0fde04e2708

The `Frontend` Linear project belongs to the separate frontend repository. Do not create backend issues there.

## Conventions

- Create issues in the `Acolhe` team and assign them to the `API` project.
- Read issues by their Linear identifier, such as `ACO-123`.
- Use Linear comments for updates, findings, and clarification requests.
- Apply and remove the labels defined in `docs/agents/triage-labels.md`.
- Close issues by moving them to the team's completed state.
- Preserve issue relationships such as blockers, blocked issues, parents, and related issues.

## When a skill says "publish to the issue tracker"

Create an issue in the `Acolhe` team and assign it to the `API` project.

## When a skill says "fetch the relevant ticket"

Fetch the Linear issue by its identifier and include its description, labels, status, relationships, and comments.
